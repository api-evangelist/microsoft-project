Available now, you can link tasks within a project using advanced dependency types such as Start-to-Start, Finish-to-Finish, Start-to-Finish, and of course the default Finish-to-Start which is already available. For the uninitiated, dependency types let you link task start and end dates as dependent on any of the other task’s start or end in the project. Accessing Dependencies You can access dependency settings in the Grid view under columns “Depends On” and “Dependents (after)”.
