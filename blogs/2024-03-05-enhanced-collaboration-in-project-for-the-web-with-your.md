We’re excited to share that as of today, you can edit shared projects in Project for the Web using a Microsoft 365 license. This frequently requested feature enables you to collaborate more seamlessly with your colleagues on projects. With this feature update, you can now access and edit the same set of capabilities in Project that you have in Planner.
