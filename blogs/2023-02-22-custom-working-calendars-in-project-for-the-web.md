If you have either Project Plan 3 or Project Plan 5 subscriptions, you can create custom work week calendars for each project directly in Project for the web. Each project is created using a default work template, which is based on the typical Monday through Friday work week. However, not all teams follow this traditional work week and need a way to schedule their tasks based on their own unique availability.
